# Mini LCS - Frontend

The frontend of the Mini Loan Collection System, built with React and Vite.

## Prerequisites

- **Node.js** (LTS version recommended)
- **npm** or **yarn**

## Getting Started

Follow these steps to get the frontend running:

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```

The application will be available at [http://localhost:5173](http://localhost:5173).

## Features
- **React 19**: Modern UI development.
- **Recharts**: Data visualization for loan metrics.
- **Axios**: API communication with the backend.
- **Lucide React**: Clean and consistent iconography.

## Project Structure
- `src/components/`: Reusable UI components.
- `src/pages/`: Main application pages.
- `src/services/`: API service integration.
